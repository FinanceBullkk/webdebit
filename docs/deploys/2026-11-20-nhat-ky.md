# 20/11/2026 — Nhật ký công việc: thư mục và quyền ghi trên `hao` (NHAT-KY-01)

[Quyết định](../decisions/nhat-ky-01.md) · [spec](../../specs/nhat-ky-01.md)

Người dùng cho phép 20/11/2026 trong chat ("Cho phép" thêm một dòng cấu hình systemd). Claude làm tay qua SSH, trước khi merge PR code; code tự triển khai qua `Deploy hao` khi merge.

## Đã chạy

1. `install -d -o v7app -g v7app -m 700 /var/lib/webdebit-sheet-sync/nhat-ky` (user của `v7-ledger-api.service` là `v7app`).
2. Drop-in `/etc/systemd/system/v7-ledger-api.service.d/nhat-ky.conf`: `[Service]` / `ReadWritePaths=/var/lib/webdebit-sheet-sync/nhat-ky`.
3. `systemctl daemon-reload`. Không restart tay: lượt `Deploy hao` của PR restart dịch vụ.

## Kiểm

- `systemctl show -p ReadWritePaths v7-ledger-api.service` có thêm `/var/lib/webdebit-sheet-sync/nhat-ky`; thư mục `drwx------ v7app v7app`; dịch vụ `active`.
- Sau lượt `Deploy hao`: `store.json` được tạo trong thư mục, `GET /api/v7/nhat-ky` có `checked_at` mới (ghi kết quả ở PR).

## Gỡ

Xóa file drop-in, `daemon-reload`, restart dịch vụ; xóa thư mục nếu không dùng nữa. Code không có thư mục thì vẫn chạy, trang báo "Không lưu được".
